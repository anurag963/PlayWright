## Viewing
GitHub shows `.html` files as source, so open them from a clone:
```bash
open docs/hybrid-framework.html        # macOS; or double-click the file
```
The pages are self-contained apart from Google Fonts and the Mermaid library (loaded from
jsDelivr to draw the diagrams), so they need an internet connection. They follow the system's
light or dark theme.

The claude.ai links are private to their owner until shared from the page's Share menu.

## Keeping them current
These files are snapshots of the guides. When a framework changes (new tests, renamed fixtures),
update the guide's content to match; the README in each framework folder stays the quick reference.
